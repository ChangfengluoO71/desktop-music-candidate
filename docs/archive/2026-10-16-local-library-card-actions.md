# 本地曲库卡片操作改版

状态：代码已归档；实际菜单操作待人工验收。
日期：2026-10-16

## 目标

专辑和歌手卡片下方的“播放 / 下一首 / 队列”按钮占用较多空间，封面墙显得拥挤。将主要操作收进封面覆盖层，保留直接播放，并将次要操作放入菜单。

## 交付

- 封面右下角显示圆形播放按钮。
- 封面右上角显示更多操作按钮；菜单包含“下一首播放”和“加入播放队列”。
- 卡片主体仍用于打开专辑或歌手筛选。
- 按钮包含可访问名称和测试标签；Compose UI 测试流程已更新为先打开更多菜单再选择操作。

## 验证记录

- 在 JDK 25 下运行源码版 `run`，窗口成功显示本地曲库；捕获到封面操作图标正常显示的窗口画面。
- `run` 期间 Kotlin 编译任务完成，应用进程持续运行。
- 本轮未运行自动化测试，未点击菜单，也未验证高 DPI；不得据此宣称完整 GUI 验收通过。
- 默认 JDK 17 的首次启动被项目版本检查拒绝；切换到已安装的 JDK 25 后启动成功。

## 后续
