# DMC 本地音乐播放器 P1

**状态：R3 代码与自动化验证完成；Windows 原生播放器和交互验收仍未完成。**

P1 以离线本地音乐播放和曲库管理为中心。生产播放器统一通过 libmpv/JNA 输出到 Windows WASAPI 共享设备；整个播放界面集成在 DMC 主窗口内。本文区分代码、自动化和真实 Windows 验收，不把构建或 UI 测试当作真人操作证据。

## 产品边界

- 播放器只读取用户选择的本地音频、歌词、封面和曲库索引；播放不需要登录或网络，也不依赖网易云 Song ID、Cookie 或在线音源 URL。
- 扫描、播放、歌词读取和封面读取不修改源媒体文件。移除索引只改变 DMC 数据库。
- 在线搜索和下载仍是独立的网易云模块，不属于本地播放身份和播放队列。
- 不承诺 bit-perfect、独占设备、无损重采样或特定高解析输出。

## 当前实现

### 播放器与主窗口

- libmpv 是唯一生产播放后端，使用 JNA 和专用原生工作线程；音频输出固定为 WASAPI shared。引擎初始化配置 audio-display=no，音频文件内嵌封面由 DMC 展示，不要求启动独立 mpv.exe 窗口。
- 缺少 libmpv 或音频设备不可用时，界面报告错误；不自动切换到 JavaFX 或 null 输出。
- 正在播放页是主窗口内的导航页。底部迷你播放器会随页面切换持续显示，打开正在播放页不会新建播放器窗口。
- 正在播放页在宽屏采用封面/控制与歌词并排布局，在较窄窗口采用纵向布局；包含封面、曲目信息、进度、传输控制、歌词与队列。
- 队列支持播放、暂停、上一首、下一首、seek、音量、随机、循环、插队、加入队列、移除、清空和重排。播放下一首不会打断当前曲目；队列空闲时可直接开始播放。
- 歌词支持本地原文、翻译和罗马音轨道；点击时间歌词跳转。用户手动滚动后暂停自动跟随，可显式恢复；切歌或切换歌词轨道会恢复跟随。

### 本地曲库与封面

- 曲库提供专辑、歌手、歌曲和文件夹四种浏览方式。专辑/歌手采用自适应网格，歌曲列表虚拟化并可按标题、歌手、专辑、格式和时长排序；支持搜索、播放、播放下一首和加入队列。
- 库与播放器共用一个封面仓库，负责提取、解码、并发请求合并、文件变更失效和 64 MiB 解码图像 LRU 缓存。读取在后台执行，使用缩略解码和输入尺寸限制。
- 文件夹递归监听仍需用户主动启用。新增/修改/删除按路径更新索引；读取标签前等待文件大小和修改时间稳定。监听丢失、队列溢出或恢复失败时退回根目录扫描。监听和索引移除不删除原始音频。

### 格式与运行库

- R2 的 Windows 原生测试记录曾以固定本地 libmpv 运行库验证生成的 MP3、FLAC、AAC/M4A 和 WAV 样本，确认 WASAPI 输出属性与播放位置推进；这些结果证明原生后端执行，不等于当前机器有人耳听验证。
- 本次构建没有捆绑 libmpv。应用需要用户把受支持的运行库放入应用私有数据目录，或通过明确绝对路径配置。当前环境未找到固定测试版 DLL 和对应归档，因此本轮无法重做 R3 的嵌入封面原生窗口验收。
- JavaFX 旧实现和依赖仍留在源码/构建配置中作为迁移残留，但生产入口不选用它，也不会在 libmpv 失败时回退。移除这些残留须另行审核并验证安装依赖。
- 除上述原生样本外，不承诺 APE、DSD、Opus、WMA 或其他编码配置均可播放；能被扫描不代表能被解码。

## R3 自动化覆盖

- 主窗口路由、迷你播放器导航和正在播放页布局。
- 曲库四种浏览、筛选/排序、自适应浏览和大列表虚拟化。
- 播放下一首与队列顺序、歌词跳转和自动跟随控制。
- 封面缓存并发去重、无效数据和尺寸边界、失效及内存预算淘汰。
- 监听事件合并、文件稳定等待、增量更新、重叠根目录、溢出/失效 WatchKey 恢复、缺失根目录重连，以及扫描与监听并发更新保护。
- 合辑曲目精确筛选和曲目双击播放；封面变化只使相关目录缓存失效。
