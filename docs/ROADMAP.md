# DMC 产品路线图（2026-10-25 修订）

当前远端基线：main @ 6220796；最新已核实发布 v0.0.3。按**先证据和播放稳定性、再 WebDAV、后更多网盘**的顺序实施。阶段状态是计划，不是已完工标记。

## C0 — 发行版和现有播放器收口（P0，先做）

目标：建立可信发布与回归基线。完成真实安装版听音/控制、升级/卸载、DPI、多种音频格式及 UI 交互；明确默认 Gradle 0.1.2 与显式 Release 0.0.3 的版本边界，更新发布和许可证文档。保留现有本地播放接口的兼容测试。

完成门禁：有可复现的 Windows 安装版验收记录、失败项清单及复测证据。CI success 和构建成功不能替代此门。

## C1 — 只读 WebDAV 能力探测和目录浏览（P0）

- 添加 WebDAV 账号配置（HTTPS 默认；仅显式允许环回 HTTP）、凭据隔离保存、连接测试和只读目录浏览。
- PROPFIND Depth:0/1，解析 207 Multi-Status；路径解码、分页式 UI/懒加载、防无限目录遍历。
- 分别探测文件 GET、206/Content-Range、跳转/认证、连接超时和文件元数据；服务能力不足时给出明确提示。
- 单独的 MockWebDAV、至少一台真实标准服务器和一个 OpenList/rclone 适配服务器进行只读测试。

**不得在 C1 改造下载任务、删除/上传网盘文件或把 HTTP URL 强塞到 LocalTrack。**

## C2 — 云端流式播放最小闭环（P0）

- 先引入统一 PlaybackItem / SourceRef 和经鉴权的 StreamResolver；保持 LocalTrack 索引 schema 不变。
- 用 DMC 自己管理的只读 HTTP Range 数据通道向 libmpv 提供可 seek 的环回媒体流，后续可按测试结果考虑直接 HTTP 加载。
- MP3/FLAC/M4A/WAV 真正在线播放，包含暂停、进度、拖动 seek、切歌、错误恢复、连接断开。
- 将旧队列 v1 向后兼容读入新版本；不可用的远端曲目可见、可跳过、不自动播放；不得包含密码或签名 URL。
- 通过缓存和会话级 token 管理保证退出、切歌、取消后不残留连接或可用的流链接。

完成门禁：Mock、真实 WebDAV 与 OpenList 的 206 seek、随机播放、断线、401/403/404/416/429/5xx、凭据重定向隔离和队列恢复均通过；本地播放回归不下降。

## C3 — 云端曲库、元数据、缓存（P1）

- 云盘浏览加入统一曲库入口，但本地路径与远端源 ID 始终独立。
- 扫描按目录懒加载/增量发现；缓存仅保存最小文件信息、标签/封面/歌词和必要的小块音频，不默认整库下载。
- 远端曲目消失/变更、离线使用、缓存容量/逐出、缓存与账号解绑、云端曲目和本地重复匹配。
- 收藏、最近播放、跨源播放列表视为共用上层能力；先确定云端身份稳定性，避免之后再大规模迁移。

完成门禁：1 万条远端模拟条目的渐进浏览、缓存上限、断网恢复、重复/重命名和账号移除通过压力/安全回归；真实网络性能单独测量。

## C4 — 网盘生态扩展（P1/P2）

优先通过 **WebDAV 标准层**兼容 NAS、Nextcloud、rclone 和 OpenList 挂载的网盘。115、阿里云盘、OneDrive 等并非天然提供同一种公开 WebDAV 入口；通过用户自行部署的网关接入只是**可行的适配路径**，不是保证直连成功。

后续按真实需求和合法可用的认证渠道评估：Subsonic/OpenSubsonic 音乐服务器协议，其次再考虑稳定且官方授权的特定网盘 Provider。不要把 115 非官方 Cookie 接口当作长期稳定 API 的承诺。

## C5 — Windows 产品化（P2）

品牌 DMC 运行时迁移、专辑/歌手和歌词体验、系统媒体键/SMTC、设备选择与 WASAPI 独占可选项、播放历史与收藏、可配置缓存和诊断、签名与自动更新 UX。遵守安装 AppId、数据目录和 Credential Manager 兼容。

## 执行原则

每个阶段必须分别记录：代码完成、单测/集成、真实协议验证、Windows GUI、安装版回归和发布许可状态。未通过的门禁记 BLOCKED/NOT RUN；不因文档、静态审查或 CI success 标为全面 PASS。详细技术决策见 [CLOUD-PLAYBACK-DESIGN.md](CLOUD-PLAYBACK-DESIGN.md)。
