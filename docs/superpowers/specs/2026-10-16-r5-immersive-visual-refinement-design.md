# R5 沉浸播放视觉与交互修订

**状态：实现完成，Gradle 编译通过；待 GUI 人工验收**
**范围：** DMC Desktop 沉浸播放器背景来源/材质、前景封面清晰度、错误反馈和窄窗口按钮布局。

## 目标

让沉浸播放页的封面清晰、不被过度放大，背景氛围可由用户选择，且播放控件在后端不可用或数据尚未就绪时给出明确反馈。

## 用户确认的设计

### 背景来源

- 当前曲目封面（默认）。
- 用户选择的本地图片。
- 纯色背景。

### 材质预设

- **专辑雾化（默认）：** 当前背景图进行柔焦处理，叠加暗色渐层。
- **磨砂亚克力：** 适度柔焦，歌词与控制区使用半透明材质面板和细边缘高光。
- **专辑色彩渐层：** 从背景图提取主色构成柔和渐层，不把低分辨率封面拉伸至全屏。
- **纯色舞台：** 使用用户选择的暗色，保证歌词对比度。
- **自定义壁纸：** 从本地选择图片；用户可搭配其他材质预设。

设置分别保存来源与材质。自定义图片只保存本地路径，不上传、不写入日志；路径丢失或图片无效时回退到专辑雾化，并在设置中显示原因。

## 封面与背景处理

- 前景封面保持原始宽高比，使用 Fit，不裁切；按图片实际像素和屏幕密度限制显示大小，避免放大低分辨率封面。
- 背景与前景分别解码；背景使用更高的有界长边尺寸和现有缩略图缓存，柔焦由 Compose 渲染；不能在播放进度更新时重新解码或处理。
- 解码和像素处理继续使用受限图片解码路径；图片失败不得影响播放、歌词或其他控件。
- 所有材质都叠加足够的暗色/对比度处理，确保浅色封面和亮壁纸下歌词可读。

## 交互反馈

- 沉浸页始终显示播放引擎错误；不得只在普通播放页显示错误。
- 时长为 0 或尚未加载时，进度条继续禁用，同时显示明确原因。
- 窄窗口下退出按钮始终可见，布局/队列/全屏和传输按钮可横向触达；键盘快捷键和 Esc 退出保持可用。
- 播放、队列、布局、全屏、退出继续调用现有 PlayerViewModel/窗口状态，不创建第二个播放实例。

## 兼容与范围

- 新增设置字段在 JSON 中使用可选字段及默认值读取，旧设置文件继续可用；本次不变更 schema 版本。
- 不升级 Kotlin/Compose，不引入新的运行时播放依赖。
- 不修改 Android 源码，不改下载/网络功能。
- 不提交、不推送、不合并、不发布。

## 验收

- 设置中的来源和材质可选择、保存并在重启后恢复；旧版设置仍可读取。
- 前景封面不裁切，低分辨率封面不被放大到模糊尺寸。
- 雾化、亚克力、色彩渐层、纯色与自定义壁纸均显示正确；无效壁纸安全回退。
- 无播放引擎时，沉浸页显示具体错误；时长未就绪时进度条禁用且有说明。
- 窄窗口下所有重要按钮可见或有明确的可访问布局。
- 本轮仅做 Gradle 编译验证；不添加或运行测试。

## 实现记录

- 设置已加入背景来源、材质、图片路径和纯色值，旧 JSON 字段缺失时读取默认值。
- 前景封面使用 Fit，并按解码图像像素限制显示尺寸；专辑背景上限为 1,024 px。
- 自定义壁纸按大小及安全解码规则读取，失效时回退到专辑封面；纯色与专辑取色渐层可选。
- 亚克力材质给歌词与控制面板增加半透明底色和描边；沉浸页显示播放错误及零时长提示。
